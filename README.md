# שם הגדולים — מן הערך אל הרשת | גרסה 1.4

גרסה זו ממשיכה את שפת העיצוב של 1.3 ומחברת את מפת הבית ואת ארבע שאלות המחקר למסד הנתונים המלא.

## הפעלה

1. חלצו את כל קובצי ה־ZIP לתיקייה.
2. ב־Windows הפעלו `START_LOCAL.bat`. ב־Mac/Linux הפעילו `./start_local.sh` (נדרש Python 3).
3. פתחו `http://127.0.0.1:8765/`. הגלישה אל האתר המקומי אינה מצריכה אינטרנט. העשרת Wikidata בלבד מחייבת רשת.

אין לפתוח `index.html` ישירות דרך `file://`, משום שדפדפנים חוסמים קריאת קבצי JSON באופן זה. העלאה של כל תוכן התיקייה ל־GitHub Pages נתמכת באמצעות ה־workflow הקיים.

## שיפורים בגרסה 1.4

- **סרגל ניווט:** דוחות ושיטות אחרי המרחבים התפעוליים ולפני ולידציה.
- **רשת פתוחה:** ניווט חופשי בצמתים של כלל 5,124 הישויות באמצעות קשתות מתוך גרף הידע; בחירה בצומת פותחת את סביבתו. הצומת המרכזי פותח את הניתוח המלא. הוספנו חיפוש נקודת מוצא, סימון מסלול, חזרה וקדימה, דפדוף בין שכנים, בחירת מספר שכנים, הזזה וגלגלת להגדלה.
- **שלוש שכבות ראיה:** A (מבנה הערך), C (קשר מנוסח במפורש), B (הופעה משותפת). B נטענת רק לפי דרישה. קשר מסוג B אינו טענה ליחס היסטורי.
- **ארבע שאלות המחקר:** הוספנו נתוני קורפוס, דירוג מתעדכן, חיפוש בכל הישויות, פילטר אדם/ספר/מקום, מדדי הופעה וקשרים, ובחירה המעבירה לניתוח, לרשת, למפתח ולמקור. ניתן להגדיל מ־10 עד 100 תוצאות בטבלת המחקר; המפתח הראשי נשאר נגיש לכל הישויות.
- **הסברים לפי המאמר:** לכל אחת מארבע ההדמיות מפתח 'מה רואים / מה אפשר ללמוד / מה לא להסיק'; גם ביתר מרחבי העבודה מופיעים הסברי קריאה מתודולוגיים.
- **הגדלת גרפים:** מצב fullscreen חי ולא העתק תמונה סטטי, לרשת הבית, ארבע ההדמיות, גרפים אישיים, רשת כללית, עץ, מפה וגרפים משניים. אפשר לצאת באמצעות לחצן סגירה או Esc.
- **מעברים:** כפתור 'רשת פתוחה' נוסף בראש ניתוח הישות; ניתן לעבור מתוך רשומות ארבע השאלות אל הרשת, הניתוח, המפתח והמקור.

## נתונים ותיעוד

`data/optimized/explorer-index.json` הוא אינדקס ניווט של שכבות A+C המחושב מתוך `graph_full_correct.json.gz` (15,285 קשתות מבנה ו־11,720 קשתות סמנטיות במקור לפני קיבוץ לפי זוגות). `data/optimized/explorer-cooccurrences.json` הוא אינדקס נפרד של שכבת B (103,608 קשתות הופעה משותפת במקור, לפני קיבוץ זוגות). האינדקסים אינם גרף חדש או הסקה של יחסים שלא תועדו.

העיצוב וההסברים מבחינים בין עיבוד החומר על ידי החיד״א, העריכה במהדורת בן־יעקב משנת 1852, והפורמליזציה שלנו. מספר אזכורים או מרכזיות ברשת אינם דירוג של חשיבות היסטורית.

## בדיקות

נבדקו ב־Chromium עם קבצי הנתונים האמיתיים המוזרקים כסביבת קבצים מקומית: 5,124 רשומות; ניווט מצומת לצומת וחזרה; שכבות A/C/B; סינון שכנים; הגדלה למסך מלא של רשת הבית וארבע ההדמיות ברמת חלון ההטמעה; פתיחת ניתוח יוסף קארו (278 צמתים ברשת אגו, 32 בעץ); ושימור 98 מתוך 98 מזהי רכיבי האתר המקורי. הולידציה המקורית עברה 13/13. מבחני JavaScript לא החזירו שגיאות בזמן התרחישים האלה. בדיקת רשת על שרת HTTP רגיל ו־GitHub Pages, כמו גם בדיקה ידנית של כל מצבי ארבעת קובצי ה־HTML המוטמעים, טרם הושלמו.
